# 分镜表模板与规则

用于 `short-drama-one-click-storyboard` 的 C 级逐镜头精细分镜生成与修订。

C 级逐镜头精细分镜、AI 视频逐镜提示词和 DOCX 执行稿除本文规则外，必须同步加载 `shotlist-execution-format-template.md` 并严格采用固定字段顺序；生成项目首批或校正格式漂移时，同步参考 `shotlist-gold-example-episode36.md`。

## 执行范围

本技能只输出 C 级逐镜头精细分镜，对指定场景、集数或连续片段做完整镜头拆解，不提供关键分镜表或场级分镜表。

默认规则：
- 仅在场次/集数、交付类型或分批范围不清时询问最小执行范围，不再询问分镜层级；
- 用户已明确范围，或已授权“按专业判断继续/全程不要停”时直接执行；
- 长项目按连续场景或可独立验收的镜头组分批生成。

## 分镜表字段

下表是设计信息及必填性说明，不是最终输出列。信息须映射到 `shotlist-execution-format-template.md` 的固定8项镜头卡片或场级状态锁，不新增字段、不改变字段顺序；执行备注仅供内部制作使用。

| 字段 | 必填 | 说明 |
|:--|:--|:--|
| 镜号 | ✅ | 本场内连续编号 |
| 对应场号 | ✅ | 关联剧本场号 |
| 场景锁定/精确场景描述 | ✅ | 时间、地点、天气/季节、空间布局、关键道具、人物站位、光源动机；同一场对话不得挪到另一场景 |
| 时长 | ✅ | 精确到秒，写 `15s`、`8s` 等明确值，不写范围 |
| 景别 | ✅ | 全景/中景/近景/特写等 |
| 画面内容 | ✅ | 画面中正在发生什么 |
| 机位/角度 | | 正面/侧面/俯拍/仰拍等 |
| 镜头运动 | | 固定/推/拉/摇/跟/手持等 |
| 主体动作（含台词/内心活动） | ✅ | 人物在画面中的主要动作；对白、旁白、内心活动必须插入此字段，并标注情绪节拍、停顿和语速；对白引号外禁止使用第三人称代词，必须写具体人名/群体名/物件名 |
| 多人对白定位 | 三人以上必填 | 每条有声对白子镜位逐条写 `说话人/对话对象/视线落点/视线变化/空间关系` 五项固定字段，不得只写泛化"看向某人" |
| 与上一镜衔接 | ✅ | 动作接续、视线接续、声音桥、光影渐变、焦点转移、遮挡转场、甩镜落点、匹配构图等；禁止直接硬切 |
| 光影方案 | ✅ | 主光源、方向、光质、对比、色温、阴影形状、情绪功能；必要时引用 LS 编号 |
| 前景/空间层次 | 可选 | 对话或关系镜头可写门框、窗棂、桌案、茶杯、账本、烛火、肩膀、人群缝隙等场景内物体作为前景/遮挡/景深层；不得凭空添加无关摆件 |
| 声音/音乐 | | 环境声、动作声、音乐、声音桥；对白仍归入主体动作 |
| 道具/物件 | | 画面中需要出现的关键物件 |
| 情绪功能 | | 本镜在叙事中承担的情绪任务 |
| 情绪节拍 | ✅ | 写 `情绪状态+自然语言情绪程度+触发原因+可见表演`，并与本场情绪曲线对应；不使用 `强度1-5` 数字标尺 |
| 连续性继承/本镜允许变化 | ✅ | 继承上一镜的人物、空间、道具、服装、光线、天气和背景状态；只列出本镜由可见动作造成的变化 |
| 执行备注 | 可选 | 内部制作注意事项、难点、备选方案；脚本展示版不展示该字段 |

## 逐镜头精细分镜字段内信息

C 级镜头卡片以 `shotlist-execution-format-template.md` 的固定8项字段为准，不输出“镜头目的”字段；下列起幅、落幅等信息写入对应固定字段，不另行改变卡片结构。镜头卡片内部不留空行：从 `### 镜头{集号}-{场号}-{镜内序号}｜{N}s` 标题到本镜最后一个字段连续逐行书写，字段之间、主体动作节拍之间及对白定位前后均不插入空白行；镜头之间与场级信息之间可保留空行。AI 视频执行版追加字段也遵守本规则；DOCX 卡片内部不插入空段落。

正式拍摄或 AI 视频逐镜生成所需的以下信息，写入对应固定字段；仅 AI 视频提示词按需追加到独立 AI 视频执行版：

| 字段 | 说明 |
|:--|:--|
| 起幅 | 镜头开始时的画面构图、主体位置、动作状态 |
| 落幅 | 镜头结束时的画面构图、主体位置、动作状态 |
| 主体运动 | 人物/物件/视线/空间关系在镜头内的变化 |
| 子镜位时间分配 | 超过 3 秒的分镜必须拆出 A/B/C/D 时间节拍；非对白动作镜头默认属于同一摄影机连续路径，对白镜头允许台词持续时切反应并标注 O.S. |
| 台词语速校验 | 含台词镜头必须写台词长度、台词占用时长、语速公式结果；中文台词语速必须在 300-350 字/分钟；用户要求台词使用英文时，英文台词语速必须在 300-340 words/min |
| 光影参数 | 光源动机、方向、光质、对比、色温、阴影、是否有眼神光/轮廓光/体积光等 |
| 画面连续性 | 与前后镜头在方向、轴线、道具位置、伤痕、服装状态上的衔接 |
| 与上一镜衔接 | 切入方式、动作接续、视线接续、声音接续或情绪接续 |
| AI 视频提示词 | 仅在用户明确要求 AI 视频逐镜提示词、Seedance 提示词或 AI 执行版时另行输出；脚本展示版不展示 |
| 负面提示词 | C 级逐镜头精细分镜每镜必填并在脚本展示版中展示；使用英文 `Avoid ...`，覆盖本镜专属风险与必要的通用连续性风险 |

是否必填按上表与固定执行稿模板执行；不得因本表将连续性、语速校验或逐镜负面提示词降为可选。

## 秒级时长与节奏压缩规则

- 每个镜头、子镜位、AI 视频段落都必须精确到秒，不使用"约、左右、3-5 秒"。
- `15s` 是 AI 视频片段上限/包装上限，不是默认时长。不要为了凑 15 秒添加空镜、慢动作、沉默停顿或重复反应。
- 生成 Seedance 单条提示词时，单条 AI 视频段落必须为 `4-15s`。低于 `4s` 的剪辑镜头不单独生成 Seedance 条目，必须并入前后相邻镜头，或作为同一 AI 视频段落的子镜位保留；合并后单条总时长仍禁止超过 `15s`，超过则拆成多个 `4-15s` 段落。
- 同场景相邻镜头合并：同一场景、同一连续时间线/对话链/动作链内，前后相邻镜头合计不超过 `15s` 时，必须合并为一个镜头或一个 AI 视频段落，并在"主体动作"中用 A/B/C 子镜位保留原镜头信息、精确秒数和自然衔接；不得把 `2-6s` 的同场景反应、短问答、道具视线拆成多个独立镜头拖慢节奏。
- 只有跨时间、跨空间、轴线重置、人物调度断裂或必须独立落点的戏剧节点，才可保留同场景相邻短镜头拆分；保留理由写入内部制作说明或 AI 执行版，不在脚本展示版展示执行备注字段。
- 普通动作、短对白、反应镜头优先 `3-6s`。对白期间的反应镜头必须发生在说话人台词持续时，画面切到听者/其他角色/关键道具，说话人以 `O.S.` 继续说话。
- 常规对话推进镜头优先 `5-8s`，可在同一镜头内承载 2-4 句短台词和对方反应。
- 信息密集对话、复杂动作调度、悬念累积镜头优先 `9-12s`。
- 只有长对白、追逐、复杂空间调度、强悬念积累、模型确需完整动作链时才使用 `13-15s`。
- AI 视频单条素材中台词与动作的总时长超过 `15s` 时必须连续拆分；脚本展示版按戏剧节拍确定时长，不套用 AI 素材的 `4-15s` 限制。拆分时保留原台词及其顺序。
- 镜头总时长应覆盖动作、台词、必要停顿和转场余韵。含台词镜头通常只给台词前后各留 `0.2s-0.6s` 表演/呼吸空间；长沉默必须是剧情明确要求，并写成有功能的动作/反应子镜位。
- 每完成一场分镜后做节奏压缩复核：删除不承载信息的秒数，合并重复反应，把场景建立并入人物动作。
- 末段节拍专项验收：任一镜头最后一个 A/B/C/D 节拍（通常为 C 或 D）持续超过 `4s` 时，必须至少明确写出一次可见变化，例如视线转移、道具状态确认或变化、摄影机拉开或重新构图、角色后退或位移、烛光/符文/环境状态变化。仅保持凝视、维持表情、静止或无功能停顿不计为变化；不满足时将末段压缩至 `1-3s`，或并入相邻节拍。

## 空镜、建立镜头与反应镜头压缩

- 纯空镜、环境过场、无人物氛围镜头最长 `1-2s`。
- 有主体入画的场景建立最长 `2-3s`。
- 承担关键线索、伏笔、危险逼近或悬念误导的空镜最长 `4s`，并必须写明它承载的叙事信息。
- 以上短时长规则用于剪辑分镜和节奏控制；若输出 Seedance 单条提示词，低于 `4s` 的空镜/建立/反应必须合并进相邻主体动作段落，并保留原始子镜位秒位，不可为了凑够 `4s` 添加无信息画面。
- 不要把"戏台热闹、屋内沉闷、夜色安静、众人反应"各自拉成独立长镜；能放进人物动作或对话开头的，必须合并。
- 反应镜头通常 `1-3s`；只有情绪反转、身份暴露、重大打击等强戏剧节点可到 `4-6s`。
- 禁止用"全景建立 5 秒 + 表情停顿 5 秒 + 物件空镜 5 秒"凑成一个 15 秒镜头。

## 超过 3 秒的多视角规则

单个分镜或 AI 视频段落超过 `3s` 时，必须在"主体动作（含台词/内心活动）"中写 A/B/C/D 时间节拍。非对白动作镜头默认使用同一摄影机、同一轴线和可追踪的连续运动路径；对白镜头允许在说话人台词持续期间切到听者、其他角色或关键道具反应，并把说话人持续台词标注为 `O.S.`。核心是让镜头内的信息和情绪持续变化，而不是机械切换景别。

可用子镜位类型：

| 类型 | 用法 |
|:--|:--|
| A 建立视角 | 建立场景、人物位置、光源和情绪 |
| B 关系视角 | 转向对手、道具、手部、眼神、空间距离 |
| C 情绪视角 | 进入特写、侧脸、背影、剪影、反应镜头 |
| D 信息视角 | 揭示关键物件、门口、窗外、屏幕、照片等 |

AI 视频连续性限制：
- 同一条提示词只保留一个主机位和一个主运动；机位高度、屏幕方向、焦段逻辑与画幅比例保持稳定。
- A/B/C 之间必须写出连续连接动作，例如人物趋近镜头形成自然近景、摇镜跟随视线、焦点由前景转到背景、门柱遮挡后继续同一路径。
- 禁止直接写"切到特写/突然俯拍/换到反打/镜头瞬间拉远"。确需反打或换机位时，拆成独立素材镜头，并在剪辑备注中标明切点。
- 对白反应切镜例外：画面可在说话人台词持续时切到听者或关键道具，台词用 `{说话人姓名}（O.S.）` 承接；反应切镜必须由视线、声音、动作或情绪触发，并保持轴线、站位、光线和道具连续。

自然连接方式：

- 动作接续：人物抬手、转身、坐下、递物等动作带出新视角。
- 视线接续：人物看向某处，下一个子镜位接被看见的物或人。
- 焦点转移：前景人物虚化，焦点落到背景人物/道具。
- 遮挡转场：人物经过镜头前、门框/柱子/车身短暂遮挡后换视角。
- 声音桥：一句台词、呼吸、脚步、电话声、环境声提前进入下一视角。
- 光影变化：灯光闪烁、门缝光扩大、车灯扫过、窗光移动带出新构图。

衔接耗时规则：
- 自然衔接通常由 `0.3-1s` 的动作、视线、声音或遮挡完成。
- 不要为了说明转场单独设计 `2s` 以上的"过渡镜头"；除非该过渡同时承载关键线索或悬念。
- 快节奏短剧可以使用"声音先入 + 动作接续 + 焦点落点"形成干净切换，但仍需说明不是无逻辑硬切。

## 台词与语速规则

- 台词、旁白、内心活动必须写入"主体动作（含台词/内心活动）"，不要只放在独立"对白"列。
- 对白期间需要反应镜头时，反应镜头必须发生在说话人台词持续期间；画面切到听者、其他角色或关键道具时，说话人标注为 `O.S.` 继续说话。不要写成说话人说完后才切反应。
- 同场景内说话人不在画面中但声音仍在，使用 `O.S.`；旁白、回忆、内心独白或非现场声音才使用 `V.O.`。
- `主体动作（含台词/内心活动）`中，原文对白引号以外禁止出现`他/她/它/他们/她们/它们`。动作、视线、反应、站位、情绪表演、对白定位和空间关系均重复写具体人物名、明确群体名或具体物件名；不要为了避免姓名重复而使用代词。
- 合格：`苏念锦看向苏二郎；苏二郎把状纸递给苏守田；四名黑衣人退向田埂；猎狗绳落在地上。` 不合格：`她看向他；他把它递过去；他们后退；它落在地上。`
- 原剧本逐字保留的对白引号内部可保留代词，例如`苏念锦说：“他偷不走辣椒种子。”`；不得为了代词扫描改写原台词。扫描时先排除成对对白引号内文本，再检查主体动作剩余文本，命中数必须为零。
- 台词必须贴合当下场景，不得把某场对话挪到另一个场景。
- 每条含台词分镜必须标注台词长度、台词占用时长和语速。中文台词写 `台词字数`、`语速 = 字数 ÷ 时长 × 60`；英文台词写 `词数 words`、`语速 = words ÷ 时长 × 60`。
- 三人以上场景的每条有声对白子镜位必须单独写一行固定格式：`对白定位：说话人=苏守田；对话对象=苏念锦；视线落点=桌上图纸；视线变化=先看图纸，问到关键处抬眼看苏念锦；空间关系=隔桌侧对。` 五项不得缺漏。
- `对话对象`回答"这句话说给谁听"，`视线落点`回答"眼睛此刻看哪里"，不得合并成一个模糊短语。A 对 B 说话但看向 C/物件时，写 `对话对象=B`，并在 `视线变化`说明看向 C/物件的原因和回视节点。
- 禁止使用无法唯一定位的`对方/某人/众人`。群体对象必须限定范围，例如`在场村民/苏家众人/柜台前客人`；轮流扫视群体时还要写起始与最终落点。
- 旁白、画外音或自言自语仍要填：`对话对象=无（旁白/画外音/自言自语）`，并写实际视线落点，避免模型自行配对口型或目光。
- 中文台词合格语速范围：`300-350 字/分钟`。用户明确要求台词使用英文时，英文台词合格语速范围：`300-340 words/min`。低于下限时压缩实际说话时长；高于上限时增加实际说话时长或连续拆镜。必须保留原台词，不得为满足语速删改台词；无法兼顾源稿与执行约束时列入“待上游确认项”。
- 情绪和语速必须匹配但不降速：中文克制/低声/试探保持 300-315，正常交流 315-335，争执/急促/威胁 335-350；用户要求英文台词时，英文克制/低声/试探保持 300-315，正常交流 315-330，争执/急促/威胁 330-340。压抑、犹豫、心虚、恐惧等情绪通过 `0.2s-0.8s` 的停顿、眼神、呼吸、手部动作或道具反应表达，不得把实际说话速度降到合格范围以下。
- 如果台词情绪需要停顿，停顿时间要计入镜头总时长，但不要计入台词语速分母；语速分母使用实际说话时长。
- 不要为了满足语速公式把短台词镜头拉长。短促台词可使用 `0.5s-1.2s` 的台词占用时长，镜头总时长按动作和反应需要控制在 `3-6s`。
- 同一场景内的连续问答若前后镜头合计不超过 `15s`，必须合并为一个节奏镜头，而不是每句台词拆成一个镜头卡片；合并后在子镜位中标出提问、反应、回答的秒位和语速。

示例：

```text
台词："你早就知道，对吗？"（7 字，不计标点）
台词占用时长：1.4s
语速：7 ÷ 1.4 × 60 = 300 字/分钟，合格

英文台词："Stay behind me and don't look back."（7 words）
台词占用时长：1.4s
语速：7 ÷ 1.4 × 60 = 300 words/min，合格
```

## 场景一致性与精确场景描述

每个分镜都必须重新确认场景锁定，至少包含：

- 场号和场景标题。
- 时间：清晨/午后/黄昏/深夜，必要时写季节与天气。
- 地点：具体到房间、街角、车内、楼道、屋顶等。
- 空间布局：人物相对位置、入口/窗户/桌椅/门框/镜子/屏幕等。
- 关键道具：本镜必须出现或保持连续性的物件。
- 声音环境：室内底噪、街声、雨声、风声、机器声等。
- 光源动机：窗光、台灯、路灯、屏幕、霓虹、车灯、月光等。

跨场景时必须重新建立场景，不得让上一个场景的台词、道具状态、光源或声音环境无解释地延续。

### 场景状态锁与逐镜继承

同一连续场景的首镜先建立一次"场景状态锁"，后续镜头默认继承，除非画面中出现了可见变化：

```text
场景状态锁：时间/天气=；空间布局=；门窗/家具=；人物站位/朝向=；服装妆发/伤痕=；手持物/道具位置=；主光方向/色温=；背景人群=；声音底噪=。
连续性继承/允许变化：本镜仅允许由可见动作造成的变化，例如"苏念锦把信交到苏二郎右手；房门由关变开"；未列出的场景状态保持不变。
```

执行规则：
- 下一镜起幅必须与上一镜落幅在人物位置、朝向、手持物、门窗状态和光源方向上可连续。
- 人物出入画、换位、转身，道具取放/换手，门窗开合、灯光改变必须在镜头内完成，或由明确的时间/空间转场解释。
- 未写入"本镜允许变化"的服装、妆发、伤痕、家具、天气、光色、背景人群和整体陈设不得改变。
- 分批生成或跨文件续写时，先读取上一镜落幅和状态锁，不得只凭当前镜头重新想象场景。

## 情绪递进与表演节拍

每场分镜生成前先写：`本场情绪曲线：起点 → 触发 → 转折 → 落点`。再给每个角色的子镜位写：`情绪节拍：情绪状态；情绪程度=自然语言描述；触发原因；可见表演`。

合格示例：

```text
本场情绪曲线：表面客气 → 账目被质疑 → 防御升级 → 证据落桌后的心虚沉默。
情绪节拍：戒备；情绪程度=压住不露；触发=对方提到账本；可见表演=笑意收住，拇指压住账页。
情绪节拍：被戳中；情绪程度=明显外泄；触发=具体数目被念出；可见表演=视线短暂落到账本，随即抬眼反问。
情绪节拍：强装镇定；情绪程度=刻意回收；触发=众人等待回答；可见表演=松开账页，刻意放慢落座动作。
```

禁止项：
- 不得整场只重复`紧张/愤怒/克制/高兴`等单一标签。
- 相邻节拍若保持同一主情绪，至少改变情绪程度、掩饰程度、动作或对话策略之一。
- 情绪变化必须由台词、动作、信息或关系变化触发，不得无依据突然暴怒、突然平静或恢复初始状态。
- 可见表演优先使用目光、呼吸、手部、姿态、距离和道具互动，不以降低台词语速代替情绪。

## AI 视频防跳帧、防乱切与防裁切

每条 AI 视频提示词必须明确：

```text
起幅：画幅比例、机位高度、景别、主体在画面位置与安全边距。
连续路径：摄影机如何平滑移动，人物如何在同一空间内完成动作，A/B/C/D 如何通过动作/视线/焦点/遮挡相连；对白反应切镜写明 O.S. 声音承接。
落幅：主体最终位置、景别、道具和背景状态。
连续性继承/允许变化：只写本镜允许发生的可见变化，以及必须保持不变的状态。
Avoid: random cuts, jump frames, camera teleport, abrupt reframing, sudden crop, unexplained zoom, axis flip, changing lens mid-shot, subject leaving frame unintentionally, character appearing/disappearing, prop teleportation, wardrobe change, lighting/weather shift, background reconstruction, layout drift, inconsistent character identity, text, watermark.
```

构图规则：主体头顶、手部和关键道具保留合理安全边距；人物移动时由摄影机跟随或预留运动空间，不得依赖突然裁切重新居中。景别变化只能由连续推拉、人物趋近/远离、焦点转移或遮挡接续完成。真正的反打、俯拍或跨轴镜头拆成独立素材镜头，不塞进同一条连续生成提示。

## 对话前景与空间层次

对话镜头可以借当前场景的物体作为前景，增加画面丰富度和关系压力，但前景必须来自场景本身，并且有叙事功能。

常用选择：

| 场景 | 可用前景 | 功能 |
|:--|:--|:--|
| 堂屋/正堂/书房 | 桌案、茶杯、账本、烛火、屏风、门框 | 压住谈判、审问、家庭冲突的空间关系 |
| 院落/祠堂/街市 | 柱子、门洞、人群肩膀、灯笼、摊位、树影 | 建立围观、偷看、动线遮挡和空间纵深 |
| 车内/楼道/房间门口 | 车窗反光、门框、楼梯扶手、半掩门、窗帘 | 表现隔阂、窥视、危险临近 |
| 作坊/厨房/店铺 | 货架、锅灶、工具、蒸汽、柜台 | 让职业空间参与叙事，避免纯头像对白 |

执行规则：
- 前景遮挡通常控制在画面 10%-35%；悬念揭示可更高，但落幅必须看清主体和关键信息。
- 同一场连续对话要轮换固定中景、过肩、侧面、手部/道具、反应、焦点转移，不要每句台词都推近人物脸。
- 前景物体必须和剧情、人物关系或空间位置有关；不得为了“好看”新增剧本没有的花瓶、纱帘、烟雾、装饰物。
- 对话重点仍落在台词、眼神、手部、道具或对方反应上；前景只是空间层次，不是新的叙事主体。

## 光影与运镜提示词规则

生成 AI 视频提示词或逐镜头精细分镜时，按需加载：

- `lighting-shadow-manual.md`：选择 LS 光影类型，补齐光源、方向、光质、对比、色温、阴影和负面提示词。
- `seedance-camera-movement-library.md`：选择 CM 运镜类型，补齐一镜一主运镜、起点、终点、速度、景别和负面提示词。

光影最小字段：

```text
Lighting: {LS编号/光影类型}，{剧情意图}。
Light source: {窗光/台灯/路灯/屏幕/车灯/月光/霓虹等}。
Direction: {front/side/back/top/under/three-quarter}。
Quality: {soft/hard/diffused/focused}。
Contrast: {low/medium/high/extreme}。
Color temperature: {warm/cool/mixed warm-cool}。
Shadow: {soft shadow/deep shadow/striped shadow/silhouette/volumetric beam}。
```

运镜最小字段：

```text
Camera movement: {CM编号/英文关键词 + 中文说明}。
Start frame: {起幅构图、主体位置、景别}。
End frame: {落幅构图、主体位置、景别}。
Speed: {slow/gentle/steady/fast/sudden}。
Shot & lens: {景别、焦段/镜头感、构图}。
Avoid: random cuts, extra camera movement, broken spatial continuity, inconsistent character identity, text, watermark。
```

## 运镜多样性与推镜限制

生成逐镜头精细分镜或 AI 视频提示词时，必须主动丰富镜头使用，禁止大量重复 CM-02 推镜头。

硬性规则：
- 连续推镜禁止。
- 每 8-10 个镜头中，CM-02 推镜头最多 1-2 个；只有心理逼近、危险压迫、证据落点、身份揭示等必要场合可保留。
- 推镜必须写清路径类型：正轴推进、侧向推进、横移推进、低机位推进、前景遮挡推进、斜线推进接揭示、过肩推进。不得只写“慢慢推近”。
- 推镜终点必须落在表情变化、证据物件、权力关系或身份揭示之一；没有明确落点的推镜必须改成其他运镜。

替代策略：

| 需求 | 优先替代 |
|:--|:--|
| 对话压迫 | 固定镜头 + 前景物件、过肩构图、侧面近景 |
| 揭示线索 | 摇镜/俯仰、焦点转移、前景遮挡揭示 |
| 人物移动 | 横移、跟拍、稳定器跟拍、轨道镜头 |
| 孤独或败局 | 拉镜、俯拍上升、固定远景 |
| 关系对峙 | 过肩、轨道、环绕、低角度运动 |
| 突发打断 | 甩镜、快速摇镜、变焦 |

每完成一场分镜后做运镜复核：统计 CM 编号分布；如果 CM-02 明显偏多，保留最有剧情落点的 1-2 个，其余改写为上表替代方案。

## DOCX 友好镜头卡片格式

当用户要求 DOCX 使用版、AI 视频逐镜提示词、或分镜需要直接交给制作人员时，不使用超宽 Markdown 表格，改用以下镜头卡片。正式文件仍可先保存为 `.md`；若用户明确要求 `.docx`，再生成同名 Word 文件。

实际交付 `.docx` 时必须接入 `documents` 技能的渲染检查流程：

1. 使用紧凑执行稿版式生成 Word 文件，镜头卡片优先，避免超宽表格。
2. 运行 `render_docx.py` 将 DOCX 渲染为 `page-<N>.png`，必要时同步输出 PDF 仅作 QA。
3. 逐页以 100% 视图检查：无文字裁切、重叠、表格破裂、页眉页脚错位、缺字、异常换页。
4. 发现问题必须修正 DOCX 并重新渲染，直到页面干净。
5. PNG/PDF 渲染物默认不交付；只给最终 DOCX。若 LibreOffice/`soffice` 缺失导致无法渲染，交付时必须说明视觉 QA 未完成。

镜头卡片直接使用 `shotlist-execution-format-template.md` 第3节的固定8项紧凑模板；成品参见 `shotlist-gold-example-episode36.md`。从 `### 镜头` 标题到最后一个字段不留空行，DOCX 对应为卡片内部不插入空段落。

## 分镜生成原则

- 默认采用 C 级逐镜头精细分镜，只在执行范围不清时确认最小必要信息；
- 按已明确或授权采用的场次/集数与批次范围完整拆镜；
- 长项目不要一次性输出超长全片逐镜头分镜，必须分批；
- 不得以只拆关键场景或高执行难度场景替代已约定范围的完整拆镜；
- 文艺/克制关系戏要避免过度花哨镜头；
- 分镜必须服务剧本情绪，不替剧本补情节；
- AI 视频提示词必须使用精确秒数、自然衔接、光影、运镜和负面提示词；时长按戏剧节拍选择，不默认 15 秒；脚本展示版每镜展示负面提示词，不展示 AI 视频提示词或执行备注；
- 同场景相邻镜头合计不超过 `15s` 时必须合并为一个镜头/AI 视频段落，并用 A/B/C 子镜位保留原信息；只有跨时间、跨空间、轴线重置或独立戏剧落点才可拆分并备注理由；
- Seedance 单条提示词必须控制在 `4-15s`；低于 `4s` 的剪辑镜头合并进相邻段落，合并后超过 `15s` 则拆分；
- 对话镜头可用当前场景的门框、桌案、茶杯、账本、窗棂、肩膀、人群缝隙等作为前景/遮挡/景深层，但不得新增无关物件；
- 运镜必须多样化，禁止大量推镜；每场完成后统计 CM-02，连续推镜或过密推镜必须改写；
- 空镜、建立、反应必须优先压缩，只有承载线索/伏笔/强情绪转折时才延长；
- 含台词镜头必须通过语速公式校验，不合格时调整实际说话时长或连续拆镜，不得删改原台词；
- 三人以上场景的每条对白子镜位必须使用固定五字段：`说话人/对话对象/视线落点/视线变化/空间关系`；A 与 B 对话时不得无理由看向 C 或别处，偏离时必须保留 `对话对象=B` 并写明戏剧目的；
- 每场必须先写情绪曲线，每个角色子镜位写"情绪状态+自然语言情绪程度+触发+可见表演"，不得整场重复单一情绪词或使用 `强度1-5` 数字标尺；
- 同一连续场景必须建立状态锁并逐镜继承，人物、道具、服装、家具、光源、天气和背景变化必须由可见动作或明确转场造成；
- 非对白动作镜头中的 A/B/C 是连续时间节拍，不是多机位硬切；对白镜头允许在说话人台词持续期间切反应镜头，并把说话人持续台词标注为 `O.S.`；AI 视频执行版必须写起幅、连续运动路径或对白镜头组切换逻辑、落幅、安全构图和防跳帧/防乱切/防裁切负面提示词；
- C 级逐镜头精细分镜每镜必须给出英文 `Avoid ...` 负面提示词，先写 3-8 项本镜专属风险，再补必要的通用连续性风险；不得用一条全局模板代替逐镜风险分析，不得写 `Avoid all cuts` 或禁止计划内的 O.S. 反应切镜；
- 主体动作、视线、反应、站位、情绪表演和对白定位说明中，原文对白引号内部除外，禁止使用`他/她/它/他们/她们/它们`；全稿扫描命中数必须为零；
- 可以给镜头建议，但不要冒充最终导演方案；
- 拍摄清单、道具清单等额外交付不属于本技能执行范围；场景调度信息写入状态锁与固定镜头字段。

## 分镜输出节奏

逐镜头精细分镜：
- 建议每次 1-3 场；或
- 每次 20-40 个镜头；
- 每批末尾注明已完成范围、累计时长、下一批起点和须继承的状态锁，并附执行验收记录；
- 已授权范围内可连续推进，不设置额外批次确认点；仅在源稿缺口或矛盾无法执行时列出待上游确认项。
