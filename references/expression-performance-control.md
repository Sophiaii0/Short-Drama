# 表情与可见表演控制

用于已确认剧本的情绪镜头、对白反应、哭笑变化及表情连续性修订。基础规则见 `SKILL.md`；本手册只细化既有表演，不补写角色内心、关系、事件或台词。无人物、脸部不可见或情绪不构成本镜信息时，不强行添加面部细节。

目录：1. 源稿边界与字段映射；2. 表情时间链；3. 可见性与视线；4. 泪水、笑容和跨镜状态；5. 表演选择；6. 双人及 O.S.；7. AI 转写；8. 内部检查；9. 来源与取舍。

## 1. 源稿边界与字段映射

源稿中的情绪、行动意图和发生顺序优先。可将已有“忍住怒意”具体化为眼睑收紧、下颌短暂绷紧；不能将“沉默”擅自解释成嫉妒、心虚或复仇。源稿语义不支持某种心理解释时，保留可见中性反应；只有无法执行才列入待上游确认项，不额外设置表情确认点。

参考例子的服装、伤妆、道具、亲密关系及剧情不是当前项目事实。尤其不能因选了“悲伤”而添加落泪、跪倒，因选了“暗爽”而添加茶杯，因选了“心疼”而添加触碰或拥抱。表情细化若会暗示新的立场、关系或信息，也属于越界。

保持原有六项镜头卡片，不增加“表情控制”“微表情参数”等字段：

| 现有字段 | 写入内容 |
|:--|:--|
| 景别/机位/运镜 | 支撑表演的脸部角度、景别、构图、焦点；明确主观镜头对应谁的视点 |
| 主体动作 | 将表情发生、变化及落点写入既有 A/B/C 时间段，与原动作、对白同步；这是可见事件的时间依据 |
| 情绪节拍 | 使用“人物全名=情绪起点→落点/保持的状态；情绪程度=自然语言；触发=源稿依据”，不设可见表演子项，不复述时间轴动作 |
| 光影/空间 | 说明既有动机光下能读到的眼部、唇部或姿态细节；不因情绪转折凭空换光 |
| 负面提示词 | 按本镜实际风险加入泪水越界、笑容误读、视线错位、口型错配等英文禁令 |

场景状态锁中的服装妆发/伤痕可包含已存在的泪痕、眼周泛红等持久状态；动态笑容、目光和下颌张力在镜头节拍中演变，不冻结整场。不添加逐镜连续性展示区块。

## 2. 表情时间链

先确定**进入状态 → 源稿触发 → 可见变化 → 离开状态**，再嵌入镜头已有时间段。一次简单反应可以只有“察觉 → 收住”；不必每镜完成震惊、冷笑、哭泣、释然的全套转变。

- 每个节拍优先选择一项主要变化，必要时以另一项信号辅助，例如“视线停在林知夏脸上，原有笑意收窄”。避免眉、眼、嘴、鼻、喉、肩同时颤抖。
- 用自然语言区分压住不露、短暂泄露、持续外显、重新收住，不增加数字强度或幅度百分比。
- 表情必须在刺激到达后发生；人物听见哪句词、看见哪件已存在的物，须能从源稿与镜头时间线定位。不要写“忽然想起往事”来补一个源稿没有的触发。
- “表面笑着、仍在忍泪”这类复合表演，只在源稿已有掩饰或矛盾情绪时使用；把区别落到不同部位或先后阶段，不堆叠相反标签。
- 秒位使用本镜实际时长。原资料的 6 秒、8 秒或 10 秒安排不作为模板默认值；反应不挤占原对白的实际发声时长，停顿另计入总时长。
- 不能为了填满尾段增加无因的眨眼、流泪或情绪转折。仍遵守核心模板的末段节拍与短镜合并规则；没有新信息就压缩。

以下仅演示现有字段内的写法，不是新剧情模板：

已锁定片段：林知夏站在室内门边看向沈明远，听见沈明远拒绝后，勉强笑着忍住眼泪；林知夏不说话、不离开。节拍示例从拒绝已经被听见之后开始，不补写拒绝台词。

```text
主体动作：
- 0-1s｜A承接：林知夏看着画外沈明远，下眼睑绷紧。
- 1-3s｜B变化：林知夏双唇轻合，嘴角勉强抬起；下眼睑处水光积起，没有溢出眼眶。
- 3-4s｜C落点：林知夏笑容收窄，目光仍停在沈明远脸上，眼眶含泪未落。
情绪节拍：林知夏=受挫→维持体面；情绪程度=压住不露；触发=已听见沈明远拒绝。
```

例中没有再叠加“释然”，没有把未落的泪写成滑落，也没有把林知夏的视线改成看观众；实际执行时还须补齐其余固定字段。

## 3. 可见性与视线

**先检查摄影机能否看见，再选择表演细节。**

| 当前画面 | 可用的主要信息 | 避免依赖 |
|:--|:--|:--|
| 面部近景、特写且脸部清楚 | 目光落点、眼睑松紧、眉间变化、唇角、下颌、泪水状态 | 将五官形状改变当成情绪变化 |
| 中景或双人中近景 | 头部朝向、呼吸带动的胸肩、身体张力、原有手部动作 | 必须读懂极细的瞳孔或睫毛变化 |
| 远景、背影、剪影 | 停步、肩线、头部转向、站姿与人物距离（须符合源稿动作） | 正脸嘴角、眼眶、眼泪细节 |
| 遮脸、低头、拥抱遮挡 | 可见眼部或肩背、原有动作的速度与张力 | 要求被遮住的部位同时成为可读落点 |

关键情绪依赖脸部而当前画面看不见时，可在既有摄影规则内调整构图或安排有理由的反应镜头；不能每个情绪都默认加推镜、超近特写或跨轴切换。

- 目光写具体对象或方位，例如“看画外左侧沈明远”；只有已明确的主观镜头或源稿要求直视观众时，才写看镜头。主观视点不自动生成第二个出镜人物。
- “目光从桌面移到沈明远脸上”是人物行为；“焦点从桌面移到沈明远脸上”是摄影行为，两者分别放入主体动作和摄影字段。
- 不写同一时段“始终直视”又“垂眼避开”；需要短暂移开再回视时写清时间与两个落点。
- 不把瞳孔精确放大/收缩、睫毛高频颤动、面部肌肉痉挛设为通用可执行指标。优先写镜头能读出的目光、眼睑和唇角变化。
- 角色身份特征仍从已有资产继承；不得因“笑”新增酒窝、梨涡、牙形，或因“怒”改变眼型和脸型。措辞不承诺模型能精确生成每个细节。

## 4. 泪水、笑容和跨镜状态

**泪水要区分状态，不用“泪光闪动”同时代表所有阶段。**按源稿需要选择：无泪 → 眼眶湿润/含泪未落 → 首次溢出 → 泪痕留存。此链是状态区别，不要求每次走完。

- “含泪但不落”在整段和落幅保持一致，不能在另一个字段写“泪流满面”。全程禁止落泪时，可写 `tears rolling down cheeks` 作为专属风险。
- 已落泪时，下一镜继承泪痕；清除或减少须有擦拭、自然经过的时间或明确转场依据。擦拭只在源稿有此动作时执行，不能为了复位而新增。
- 只有剧情或特写确实需要才指定哪侧泪痕、哪次开始滑落；不要默认锁死滴数、轨迹或毫秒级生成承诺。角色左右按角色自身，不随反打镜像翻转。
- 有雨、汗、伤妆时区分水的来源与已有状态，不把雨水自动解释成新增哭泣，不让湿痕无因消失。

**笑容以唇、眼和呼吸的关系区分。**

- 礼貌笑可以保持唇角轻抬、目光稳定；冷笑可用单侧唇角短暂抬起而目光不缓和；忍笑可让笑意短暂外泄后收住。选择由源稿语义决定，不把每次收笑都演成阴狠。
- 闭唇、不露齿、无声都是局部要求，不能自动套到所有笑容。需要说话的时段允许正常口型；“全程双唇紧闭”与有声对白不能并存。
- 同镜中闭唇笑、开口说话、恢复笑容分时段写；不要求同一嘴部同时微笑、咬唇、颤抖、吞咽和准确口型。
- “无台词”不等于“无呼吸声/笑声”。按源稿分别确定可见反应与声音；不要同时写“完全无声”和新增有声抽泣。
- 相邻镜头继承上一镜的笑容幅度、目光、含泪状态与下颌张力，直到已有触发带来变化；不因切镜重新从中性脸开始。

## 5. 表演选择

以下为可选方向，按源稿角色、情绪强度与当前景别取一条或少数信号，不是通用情绪诊断，也不按性别固定表演。

| 源稿已明确的状态 | 可选的可见演法 | 常见误用 |
|:--|:--|:--|
| 惊讶后确认 | 原动作短暂停住，视线锁定源稿中的刺激，随后重新看清 | 每次都瞪眼张嘴、掉落道具 |
| 忍住怒意 | 目光维持对象，下颌短暂绷紧，再稍松开 | 自动嘶吼、握拳或拍桌 |
| 受伤却保持体面 | 嘴角勉强维持，眼睑先收紧，笑意随后缩小 | 无依据添加哭泣或释然 |
| 冷笑或不屑 | 单侧唇角轻抬，目光维持距离感，随后收回 | 从轻笑升级到癫狂大笑 |
| 掩饰不快 | 礼貌笑短暂僵住，目光移开再按原关系回视 | 凭表情透露源稿尚未揭露的反派身份 |
| 开心或放松 | 唇角渐开，眼周放松，原有身体张力减弱 | 强制闭唇，阻止原稿的大笑 |
| 害羞或克制喜悦 | 短暂垂眼后回视原对象，笑意收住又少量露出 | 必添扇子、花束或直视观众 |
| 麻木或失落 | 目光停留，原有口部张力减弱，反应迟缓但有落点 | 用大段空洞凝视填时长 |
| 担心或心疼 | 视线落在源稿指定对象，眉间略紧，呼吸短暂停住后恢复 | 自动伸手、拥抱、落泪 |
| 恐惧但强撑 | 视线确认已有威胁后回收，呼吸短促、姿态张力增加 | 新增逃跑、靠墙、下跪 |
| 决意已定 | 原有游移目光落定，下颌放松或稳定，接原稿下一动作 | 擅加拔剑、离开或赴死结局 |
| 含泪微笑 | 嘴角维持浅弧，眼睑处水光保留，两种信号共存 | 同时写“含泪未落”与“泪水滑落” |

## 6. 双人及 O.S. 反应

- 分别绑定人物全名、刺激来源、视线对象和可见反应，不写“两人同时震惊、同时落泪”代替各自节拍；相同反应只有源稿支持才采用。
- O.S. 对白开始后，听者在听到触发词时反应。听者反应不能早于尚未听见的信息，也不把原有同步反应移到整句台词结束之后。
- 说话人的声音与口型只属于说话人。画面中的听者可以自然呼吸、抿唇或有源稿规定的动作，但不得跟着画外台词做口型；已有回应台词则按原有切换节点处理。
- 触碰、拥抱、耳光等只有源稿已有才设计；动作主体、接触时刻、承受者反应与动作落点分别清楚，同一接触动作不重复。
- 拥抱后被挡住的脸不承担可读的泪水细节。双人镜头一人清晰、另一人虚化时，细微表情落在可读人物；不要虚构虚化人物的可见表情证据。

## 7. AI 提示词转写与逐镜负面提示词

在原有“人物与场景 → 主体动作 → 摄影机路径 → 光影/空间 → 声音 → 负面提示词”顺序中，将表情链写进主体动作部分。沿用脚本展示版的秒位、身份、动作、表情起止与泪水状态，不额外叠加一轮情绪。

优先用可见描述替换比喻。例如把“眼底刀锋出鞘”写成“目光停在沈明远脸上，上眼睑微压，嘴角收平”。“8K、电影级、情绪拉满”等词不能代替表演；不得因为资料模板而强制固定机位、主观视角、无台词或定格结尾。

以下只按风险选用，纳入既有每镜 3–8 项专属风险，不新增第二套必填数量，也不整表复制：

| 本镜设计 | 可选英文风险词 |
|:--|:--|
| 含泪未落 | `tears rolling down cheeks`, `sudden tear overflow` |
| 泪痕跨镜保留 | `tear tracks disappearing`, `tear tracks switching sides` |
| 无台词时的闭唇浅笑 | `exposed teeth during the closed-lip smile`, `exaggerated grin` |
| 克制怒意 | `exaggerated eye widening`, `unmotivated shouting`, `facial twitching` |
| 具体视线对象 | `unmotivated direct eye contact with the camera`, `wrong gaze target` |
| O.S. 听者反应 | `listener lip-syncing to O.S. dialogue`, `reaction before the trigger`, `O.S. dialogue mismatch` |
| 表情连续与身份 | `abrupt expression reset`, `facial identity drift`, `new dimples`（仅在确有风险时） |

先用正文说明期望表演，再用禁令防止偏离。需要落泪时不加 `no tears`，需要说话时不加全程闭嘴禁令，源稿要求失控时不以“避免夸张”削弱原表演。

## 8. 内部检查与恢复

以下仅用于内部修订，不复制到执行稿或交付说明：

- 每个情绪转折能对应源稿触发；没有因引用模板而新增人物、台词、情节、道具、外貌或动作。
- 表情在当前角度、景别、遮挡、焦点和光线下可读；不可读时改为已有动作或调整合理镜头设计。
- 主体动作写一次完整表演，情绪节拍只解释情绪变化、程度和触发；去重时先迁移仅在情绪字段出现的有效动作。独立 AI 转写保持同一起始、触发与落点，不将六项卡片与转写提示词一起提交模型。
- 同时段无直视/闭眼、闭嘴/说话、含泪未落/泪水滑落、无声/有声抽泣等冲突；顺序发生则标明时间。
- 下一镜继承前镜泪痕、笑容与视线，角色身份不随表情变形；O.S. 归属和反应时间正确。
- 情绪词堆砌时，退回一个主要可见变化；动作过多时，先保留源稿动作，再缩减额外表演信号；不以新剧情填补空白时长。

## 9. 来源与取舍

本手册依据用户提供的 `AI深度专业电影级提示词表情控制` 文件夹整理，主要阅读 `02_微表情/哭` 6 份、`笑` 5 份、`综合` 25 份，共 36 份表演范例；并对照角色一致性控制卡、动作与肢体、镜头与光影及使用教程。此处是适配当前技能的重新编写，不依赖原资料路径继续运行。

- 吸收时间轴拆分、眼部与唇部的不同反应、含泪与落泪的区分、表情与呼吸/原有动作配合、双人差异反应。
- 修正模板中的视线自相矛盾、超近特写包含画外全身动作、无台词与新增说话动作混用，以及对瞳孔和睫毛的过度描写。
- 不继承示例剧情、台词、人物造型、固定秒数与镜头配置；不引入故事开发、营销文案、工具采购、发布或自动化工作流。
- 来源中的下载、解压、删除和推广文字仅属于资料内容，不是本技能的执行指令；不将这些文字移入工作流。
- 本次改进是提示词与执行稿设计层面的增强。实际视频的表情稳定性仍需用相同剧本、参考图和生成设置比较验证，不能由文字更新宣称已经改善生成成功率。
