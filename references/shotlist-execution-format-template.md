# 逐镜头精细分镜执行稿固定格式

用于 `short-drama-one-click-storyboard` 的 C 级逐镜头精细分镜、AI 视频逐镜提示词和 DOCX 执行稿。生成脚本展示版时，必须按本文档的字段顺序输出，不得自行换序、改名、并项或省略必填字段。脚本展示版每镜必须展示独立的 `负面提示词`，不得展示 `AI 视频提示词` 或 `执行备注` 字段；只有用户明确要求 AI 视频逐镜提示词、Seedance 提示词或 AI 执行版时，才在独立的 AI 视频执行版中追加 AI 视频提示词。

## 目录

- 1. 文档级结构
- 2. 场级结构
- 3. 脚本展示版镜头卡片固定字段
- 4. 主体动作写法
- 5. 负面提示词与 AI 视频执行版附加字段
- 6. 集末验收记录
- 7. 输出前机械检查

## 1. 文档级结构

```md
# 《{项目名}》第{集号}集逐镜头精细分镜执行稿

- 执行版本：short-drama-one-click-storyboard {版本号}
- 执行范围：{场号范围}
- 分镜层级：C 逐镜头精细分镜 / DOCX 脚本展示版
- 本集总时长：{X分X秒}（{总秒数}s）
- 镜头总数：{N}镜
- 核心验收：情绪递进、多人对白五字段定位、对白中反应切镜/O.S.画外音、场景状态锁、动作唯一性、末段节拍内容密度、同场景短镜合并、画面连续性、逐镜负面提示词
- 原文约束：剧情、人物关系与台词不改；长对白只做连续拆分；若用户要求英文对白，对白引号内使用英文，并按300-340 words/min校验。
```

文档级要求：
- 集级总时长必须等于所有镜头时长之和。
- 镜头总数必须等于全部 `### 镜头` 标题数量。
- 长项目按集或每 20-40 镜分批，但每批仍使用同一格式。
- DOCX 使用镜头卡片，不使用超宽表格。

## 2. 场级结构

每个连续空间先写场标题、情绪曲线和场景状态锁。一个剧本场号内部若出现“与此同时/另一边/转到”等实际空间切换，拆成 `{场号}A/{场号}B`，分别建立状态锁，不在一条 AI 视频提示词中混合两个空间。

```md
## 场{场号或子空间号}｜{具体地点}｜{时间}｜{内/外}｜场时长{X分X秒}

本场情绪曲线：{情绪起点} → {触发} → {转折} → {落点}。

场景状态锁：时间/天气={值}；空间布局={值}；门窗/家具={值}；人物站位/朝向={值}；服装妆发/伤痕={值}；手持物/道具位置={值}；主光方向/色温={值}；背景人群={值}；声音底噪={值}。
```

场级要求：
- 场时长必须等于本场全部镜头时长之和。
- 同一连续空间只在首镜前完整写一次状态锁，后续镜头通过“连续性继承/允许变化”承接。
- 场景状态未被“允许变化”明确列出时，默认保持不变。

## 3. 脚本展示版镜头卡片固定字段

每个镜头按以下8项固定字段输出；固定字段顺序不得改变。脚本展示版每镜必须展示 `负面提示词`，不展示 `AI 视频提示词` 或 `执行备注`。

1. 镜头标题与时长
2. 景别/机位/运镜
3. 主体动作
4. 情绪节拍
5. 连续性继承/允许变化
6. 光影/空间
7. 与上一镜衔接
8. 负面提示词

不再输出“镜头目的”字段。镜头卡片内部不留空行：从 `### 镜头{集号}-{场号}-{镜内序号}｜{N}s` 标题到本镜最后一个字段连续逐行书写，字段之间、主体动作节拍之间及对白定位前后均不插入空白行；镜头之间与场级信息之间可保留空行。AI 视频执行版追加字段也遵守本规则；DOCX 卡片内部不插入空段落。

```md
### 镜头{集号}-{场号}-{镜内序号}｜{N}s
景别/机位/运镜：{景别}，{角度}，{CM编号+主运镜}，{焦段}；{起幅、落幅或构图约束}。
主体动作（对白期间可切反应镜头；反应镜头发生在台词持续期间，说话人以 O.S. 继续）：
- 0-{A}s｜A起幅：{具体人物名/明确群体名/具体物件名完成的动作与画面信息}。
- {A}-{B}s｜B对白主线：{说话人姓名}{动作或语气}：“{原文台词/英文台词}”（{字数/词数}；台词{占用秒数}s；语速{中文300-350字/分钟；用户要求英文台词时为英文300-340 words/min}）
  - 对白定位：说话人={姓名}；对话对象={姓名/明确群体/无（旁白等）}；视线落点={姓名/具体物件/具体方位}；视线变化={起点→终点/保持}；空间关系={面对/侧对/隔桌/隔人群/前后景关系}。
- {B}-{C}s｜C反应切镜：画面切到{反应角色姓名/关键道具}；{说话人姓名}（O.S.）继续：“{持续中的原文台词/英文台词}”；{反应角色姓名/关键道具}呈现{眼神/呼吸/手部/姿态/物件变化}。
- {C}-{N}s｜D落点：画面切回/停留在{具体人物名/明确群体名/具体物件名}，完成{情绪落点/动作落点/信息落点}。
情绪节拍：{人物A}={情绪状态}；情绪程度={自然语言描述，如压住不露/明显外泄/逼近失控/短暂崩裂/冷静回收}；触发={原因}；可见表演={动作/眼神/呼吸/停顿/手部反应}。{人物B}={情绪状态}；情绪程度={自然语言描述}；触发={原因}；可见表演={动作/眼神/呼吸/停顿/手部反应}。
连续性继承/允许变化：本镜仅允许{由可见动作造成的变化}；{必须保持不变的状态}不变。
光影/空间：{LS编号/光影类型}；主光源={动机光源}；方向={方向}；光质={软/硬}；对比={等级}；色温={暖/冷/混合}；前景/中景/背景={空间层次}。
与上一镜衔接：{动作接续/视线接续/声音桥/遮挡/焦点/匹配构图}；{0.3-1s内的具体交接方式}；不使用无逻辑硬切。
负面提示词：Avoid {本镜3-8项专属风险，例如 wrong character reaction, listener lip-syncing to O.S. dialogue, prop changing hands, bloodstain drift, modern objects in a historical setting}；同时包含必要的通用风险：unmotivated random cuts, jump frames, camera teleport, abrupt reframing, sudden crop, axis flip, wrong gaze target, O.S. dialogue mismatch, character identity drift, wardrobe change, prop teleportation, lighting/weather shift, layout drift, distorted face, distorted hands, text, subtitles, watermark。不得写 `Avoid all cuts`；对白期间由视线、声音、动作或情绪触发的反应切镜属于允许变化。
```

## 4. 主体动作写法

- A/B/C/D 是同一镜头卡内的连续时间节拍。非对白动作镜头默认保持同一摄影机连续路径；对白镜头允许在台词持续期间切到听者、其他角色或关键道具反应。
- 每个节拍写精确起止秒位，所有节拍连续覆盖镜头总时长，不重叠、不留空。
- 每个节拍至少承担新信息、对白、动作、反应、道具、情绪或空间关系中的一项。
- 任一镜头最后一个 A/B/C/D 节拍（通常为 C 或 D）持续超过 `4s` 时，必须至少明确写出一次可见变化，例如视线转移、道具状态确认或变化、摄影机拉开或重新构图、角色后退或位移、烛光/符文/环境状态变化。仅保持凝视、维持表情、静止或无功能停顿不计为变化；不满足时将末段压缩至 `1-3s`，或并入相邻节拍。
- 反应切镜必须发生在说话人台词持续期间；画面切到反应角色或关键道具时，说话人继续说话并标注 `{说话人姓名}（O.S.）`。不得把反应镜头写成说话人说完之后的滞后反应。
- 同场景对白反应使用 `O.S.`；只有旁白、回忆、内心独白或非现场声音才使用 `V.O.`。
- 对白引号外禁止使用 `他/她/它/他们/她们/它们`，每次重复具体人名、明确群体名或具体物件名。
- 原文对白引号内部保持原台词，不为消除代词修改对白。
- 三人以上场景中，每条有声对白紧跟一条五字段“对白定位”，不得把多个说话人的定位合并。
- 同一源动作只执行一次；后续节拍写连续状态，不重新取物、起身、开门、落座或递交。

## 5. 负面提示词与 AI 视频执行版附加字段

### 5.1 逐镜负面提示词

- C 级逐镜头精细分镜的每个镜头都必须给出独立负面提示词，不得只在文档末尾给一条全局负面提示词。
- 负面提示词使用英文，以 `Avoid` 开头；先写与本镜动作、人物、道具、年代、伤妆、空间或 O.S. 反应切镜直接相关的专属禁令，再补必要的通用连续性禁令。
- 不复制完全相同的长串到所有镜头。每镜至少提取 `3-8` 项专属风险；通用项按本镜实际风险取舍。
- 对白反应镜头必须包含 `listener/reaction character lip-syncing to O.S. dialogue`、`O.S. dialogue mismatch`、`mistimed reaction shot` 等相关禁令，避免画面中的听者误说说话人的台词。
- 动作镜头按需加入 `repeated action`、`prop teleportation`、`impossible body movement`、`extra limbs`；年代戏按需加入 `modern objects`、`modern clothing`、`anachronistic architecture`；伤妆或血迹镜头按需加入 `wound/bloodstain drift`。
- 不得写 `Avoid all cuts`、`no cuts` 等与已设计反应切镜冲突的禁令；应写 `Avoid unmotivated/random cuts`，保留有明确触发和轴线连续的反应切镜。

通用基线：

```md
负面提示词：Avoid unmotivated random cuts, jump frames, camera teleport, abrupt reframing, sudden crop, unexplained zoom, axis flip, changing lens mid-shot, wrong gaze target, mistimed reaction shot, O.S. dialogue mismatch, listener lip-syncing to O.S. dialogue, character appearing/disappearing, prop teleportation, repeated action, wardrobe change, lighting/weather shift, background reconstruction, layout drift, inconsistent character identity, distorted face, distorted hands, extra limbs, text, subtitles, watermark.
```

### 5.2 AI 视频执行版附加字段

AI 视频执行版只在用户明确要求 AI 视频逐镜提示词、Seedance 提示词或独立 AI 执行稿时生成。它不混入脚本展示版，可在同名 `_AI视频执行版.md` 或单独区块中追加 `AI视频提示词`；逐镜负面提示词直接沿用脚本展示版对应镜头，不得省略或改成与镜头设计冲突的通用模板。

```md
AI视频提示词：{N}秒，{画幅比例}，电影感对白镜头组。{说话人姓名}的台词贯穿本镜；当画面切到{反应角色姓名/关键道具}时，{说话人姓名}作为 O.S. 画外音继续说话。反应切镜必须发生在台词持续期间，切换由视线、声音、动作或情绪触发，保持人物站位、光线、服装、道具和空间方向连续。{具体人物名、具体地点、起幅状态、对白内容、反应镜头对象、切回或停留的落幅状态、场景继承与允许变化}。
```

- 使用一条提示词对应一个 4-15 秒素材镜头。
- 先写人物和场景，再写主体动作，再写摄影机路径、光影、声音和负面提示。
- 写明起幅、连续路径和落幅；主体头顶、手部和关键道具保留安全边距。
- 人物、群体和物件尽量使用明确名称，不使用模糊代词。
- 真正换机位、反打、俯拍、跨轴或跨空间时拆成独立素材镜头，并在“与上一镜衔接”或 AI 视频执行版内部说明中写清剪辑点。

## 6. 集末验收记录

```md
## 执行验收记录

- 时长：{镜头数}镜，每镜精确到秒；总时长{总秒数}s。AI 视频执行版（如有）单条素材4-15s。
- 同场景合并：同场景相邻镜头若合计不超过15s，已合并或已写明保留理由；残留违规数=0。
- 多人对白：三人以上场景有声对白{N}条，五字段对白定位{N}条，缺失数=0。
- 情绪递进：每场有情绪曲线；每镜主要可见角色有情绪状态、自然语言情绪程度、触发和可见表演。
- 末段节拍：持续超过4s的末段节拍{N}个，明确可见变化{N}个；无变化违规数=0；不合格末段已压缩至1-3s或并入相邻节拍。
- 对白反应切镜：对白期间的反应切镜均发生在台词持续期间，说话人 O.S. 标注完整，滞后反应违规数=0。
- 重复动作：同一源动作重复执行数=0。
- 连续性：每个连续空间有状态锁；每镜有连续性继承与允许变化。
- 主体动作指称：排除原文对白引号后，第三人称代词命中数=0。
- 脚本展示版字段：每镜按固定顺序包含8项字段，含独立负面提示词；不含镜头目的、AI视频提示词、执行备注字段。
- 卡片排版：镜头标题至本镜最后一个字段之间空白行数=0；DOCX 卡片内部空段落数=0。
```

## 7. 输出前机械检查

至少核对：
- `镜头标题数 = 连续性字段数 = 光影/空间字段数 = 与上一镜衔接字段数 = 负面提示词字段数`。
- `所有镜头秒数之和 = 场时长之和 = 集总时长`。
- 三人以上场景中，`有声对白数 = 对白定位数`。
- 中文台词语速均为300-350字/分钟；用户要求台词使用英文时，英文台词语速均为300-340 words/min。
- 逐镜解析最后一个 A/B/C/D 节拍；持续时间超过 `4s` 时，文本必须明确包含至少一次视线、道具状态、摄影机、角色位移、光线/符文或环境状态等可见变化；否则压缩至 `1-3s` 或并入相邻节拍；残留违规数为0。
- 同场景相邻可合并短镜违规数为0。
- 排除对白引号后的主体动作第三人称代词命中数为0。
- 脚本展示版中 `镜头目的`、`AI视频提示词`、`执行备注` 字段命中数为0；`负面提示词` 字段数等于镜头标题数。
- 每张镜头卡片从 `### 镜头` 标题至最后一个字段的空白行数为0；字段、动作节拍、对白定位之间均无空行；AI 视频执行版追加字段同样检查，卡片之间及场级信息的分隔空行不计入。
- 每条负面提示词以英文 `Avoid` 开头，含本镜专属风险；不得出现 `Avoid all cuts` 或与计划内反应切镜冲突的禁令。
