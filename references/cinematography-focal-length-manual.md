# 影视分镜焦段与焦距使用手册

本文件服务于 `short-drama-one-click-storyboard` 的分镜执行层，用于把剧情、人物关系和情绪任务转换为可执行的焦段、焦距与镜头感描述。

它不是“某景别必须使用某毫米数”的固定配方，也不替代导演、摄影指导和现场镜头测试。分镜可以给出明确建议，但不得把经验范围冒充唯一方案。

## 1. 核心原则

### 1.1 决策顺序

焦距选择按以下顺序执行：

1. 确定本镜的叙事任务：交代空间、建立关系、压迫、亲密、隔离、揭示或观察。
2. 确定观众位置：观众应该贴近人物、与人物平视、躲在远处，还是俯视整个空间。
3. 确定机位：摄影机与人物的距离、高度、方向和轴线。
4. 确定景别与构图：画面需要容纳哪些人物、动作、前景和关键道具。
5. 根据有效画幅选择焦距。
6. 根据表演幅度、对焦难度和视觉意图确定景深。
7. 检查与前后镜头在透视、空间尺度、视线、脸型和背景上的连续性。

最重要的执行口诀：

> 机位决定观众与人物的关系，焦距决定从该位置看见多少。先选机位，再选焦距。

### 1.2 不得混淆的四个概念

| 概念 | 含义 | 分镜中的用法 |
|:--|:--|:--|
| 焦距 | 镜头自身的光学参数，如 24mm、50mm、85mm | 精确镜头建议 |
| 焦段 | 对焦距范围或视觉类别的概括，如广角、标准、中长焦 | 视觉方向和镜头感 |
| 视角 | 实际进入画面的范围，由焦距和有效画幅共同决定 | 决定构图范围 |
| 透视 | 前后物体的大小比例与空间关系，根本上由机位位置决定 | 决定人物和空间的心理关系 |

### 1.3 关键纠错

- 50mm 装到不同机身上仍然是 50mm；改变的是画幅截取到的视角。
- 广角不直接“拉长人脸”，长焦不直接“压扁空间”。常见变化主要来自为了保持同一景别而改变了机位距离。
- 裁切系数只用于比较视角，不会把 T2 变成 T3，也不会改变镜头标称焦距。
- 分辨率、像素数量和传感器尺寸不是同一概念；4K 或 8K 不能用于推断画幅。
- 数码裁切可缩窄视角，但会损失有效像素或改变噪点表现，不等于更换真实长焦镜头的全部成像特征。
- “35mm”可能指 35mm 静态全画幅，也可能指 Super 35 电影画幅，二者不可直接混用。

## 2. 画幅与焦距换算

### 2.1 视角公式

球面镜头可使用以下公式估算：

```text
水平视角 = 2 × arctan（有效传感器宽度 ÷ 2 ÷ 焦距）
```

不同画幅保持相同水平视角时：

```text
新焦距 = 原焦距 × 新传感器宽度 ÷ 原传感器宽度
```

需要精确计算时，必须使用相机当前记录模式的有效传感器宽度，而不是只使用机身宣传页上的标称尺寸。Open Gate、16:9 裁切、2.39:1、变形宽银幕模式和电子防抖都可能改变有效画幅。

### 2.2 常用近似换算

| 画幅 | 与全画幅相同视角的近似关系 |
|:--|:--|
| 全画幅 | 基准 |
| Super 35 | 全画幅焦距 ÷ 1.45 |
| APS-C | 全画幅焦距 ÷ 1.5 或 1.6，按厂商尺寸确认 |
| M4/3 | 全画幅焦距 ÷ 2 |
| Super 16 | 全画幅焦距 ÷ 2.9 |

示例：

```text
Super 35 的 35mm × 1.45 ≈ 全画幅 51mm 的视角
全画幅的 85mm ÷ 1.45 ≈ Super 35 的 59mm 视角
```

这些数值只用于视角近似。具体镜头的畸变、呼吸、焦外、近摄表现和画面边缘特征仍需实拍测试。

### 2.3 画幅未说明时的默认写法

当剧本、项目或用户没有给出相机画幅：

- 焦段尚未确定时可写 `广角感/标准镜头感/中长焦观察感`，避免伪精确。
- C 级逐镜头分镜：可以给出 `全画幅等效焦距`，但必须明确标注“等效”。
- AI 视频提示词：统一采用 `full-frame-equivalent lens look`，提高跨模型的一致性。
- 用户确认真实机型和记录格式后，再换算成实际镜头焦距。

合格：

```text
全画幅等效 35mm 的轻广角镜头感。
35mm full-frame-equivalent moderate wide-angle lens look.
```

不合格：

```text
使用 35mm 镜头。
```

原因：未说明画幅，无法确定实际视角。

## 3. 焦段分类

以下范围用于球面镜头，是分镜起步建议，不是硬性标准。

| 视觉类别 | Super 35 | 全画幅 | 主要空间效果 |
|:--|--:|--:|:--|
| 极广角 | 8-14mm | 12-20mm | 强调近大远小、空间纵深、速度和边缘运动 |
| 广角 | 15-24mm | 21-35mm | 人物与环境并重，临场感强 |
| 标准 | 27-40mm | 40-60mm | 透视相对自然，摄影机存在感较低 |
| 中长焦 | 45-70mm | 65-105mm | 人物突出，背景简化，脸型较稳妥 |
| 长焦 | 75-135mm | 105-200mm | 空间压缩、观察感、浅景深 |
| 超长焦 | 150mm 以上 | 200mm 以上 | 远距离捕捉、强压缩、监视或竞技感 |

## 4. 景别与焦距的起步建议

必须先确定机位距离，再参考下表选焦距。

| 景别任务 | Super 35 起步范围 | 全画幅起步范围 | 主要注意事项 |
|:--|--:|--:|:--|
| 大全景、环境建立 | 12-21mm | 18-32mm | 防止人物过小、边缘变形和无信息空镜 |
| 群像、双人中景 | 21-35mm | 32-50mm | 检查人物距离与前后层次 |
| 单人中景、近景 | 28-50mm | 40-75mm | 平衡人物表演与环境信息 |
| 常规人物特写 | 50-75mm | 75-105mm | 适合自然五官比例和背景分离 |
| 主观、侵入式特写 | 21-35mm | 29-50mm | 摄影机靠近人物，透视更强 |
| 大特写、细节 | 75-135mm 以上 | 105-200mm 以上 | 景深极浅，注意最近对焦距离 |
| 微小物件 | 微距镜头 | 微距镜头 | 普通长焦不等于微距能力 |

不得仅凭“全景用广角、特写用长焦”自动生成焦距。以下两种特写承担的叙事功能不同：

- 广角近拍：人物侵入观众、情绪直接、空间仍然可见。
- 长焦远拍：人物被观察、与环境隔离、背景被压缩。

## 5. 焦段的叙事语义

### 5.1 广角

适用任务：

- 交代环境、狭小室内、车内、走廊或多人调度。
- 让观众进入人物附近，形成主观、亲历或侵入感。
- 强调前景、纵深、人物之间的实际空间距离。
- 强化跟拍、冲刺、打斗、车辆和快速穿越空间的速度感。
- 让多个空间层次同时参与叙事。

执行风险：

- 人脸靠近镜头时，鼻子、额头、手部会显得更大。
- 人物靠近画面边缘时，脸和身体容易被拉宽。
- 前景物体会迅速放大，容易抢走叙事主体。
- 横移、推拉和人物趋近时视差明显，场景接缝和空间错误更容易暴露。
- 过度使用广角会让所有场景都显得夸张、空旷或喜剧化。

### 5.2 标准焦段

适用任务：

- 常规对白、双人关系、家庭戏和生活流叙事。
- 需要人物与环境保持平衡，又不希望明显夸张。
- 需要摄影机存在感较低、让表演主导画面。
- 作为一场戏或整部作品的“母语焦距”。

执行建议：

- 可先设定一支工作焦距，如 Super 35 的 32mm 或全画幅的 50mm。
- 常规段落以工作焦距为基准，只有叙事关系发生变化时才明显变宽或变长。
- 同一连续场景不要无动机地在极广角和长焦之间来回跳动。

### 5.3 中长焦与长焦

适用任务：

- 传统、端正的人物特写。
- 将人物从杂乱背景中分离。
- 表现孤独、疏离、窥视、监视、命运压迫或无法靠近。
- 压缩道路、人群、山峦和城市层次。
- 纪录片、演出、体育等不能靠近主体的拍摄。

执行风险：

- 会放大微小角度抖动，需要更稳定的支撑。
- 景深较浅，演员轻微前后移动就可能脱焦。
- 摄影机离人物太远时，可能失去与表演共同呼吸的感觉。
- 纵深变化变弱，但横向人物可能很快穿过狭窄画面。
- 长焦不应只被用作“背景虚化按钮”；必须有叙事理由。

## 6. 情绪与焦段映射

焦段只提供视觉倾向，必须与机位、距离、角度、光影和表演共同执行。

| 戏剧意图 | 优先镜头策略 | 不宜机械套用的情况 |
|:--|:--|:--|
| 亲密、陪伴 | 标准或轻广角靠近人物 | 若需要端庄、浪漫美化，可改用中长焦 |
| 侵入、逼问 | 广角近机位，前景压迫 | 若角色以冷静控制为主，可用固定中长焦 |
| 孤独、被隔离 | 长焦、负空间、背景压缩 | 若孤独来自巨大环境，也可用极远广角 |
| 窥视、监视 | 长焦、遮挡前景、远机位 | 主观偷窥也可用狭缝式标准焦段 |
| 失控、眩晕 | 近距离广角、倾斜或快速空间运动 | 不得无依据制造脸部畸变 |
| 冷静、客观 | 标准焦段、固定机位、稳定构图 | 客观不等于所有镜头使用 50mm |
| 权力、威压 | 低机位广角近拍，或长焦压缩关系 | 必须根据权力来源选择“侵入”或“遥控” |
| 浪漫、美化 | 中长焦、柔和焦外、稳定运动 | 若叙事追求生活质感，避免过度美容化 |
| 喜剧、身体表演 | 广角、深景深、多人同框 | 克制喜剧可用固定中景和长时间调度 |
| 恐惧、未知逼近 | 长焦压缩危险，或广角暴露巨大空区 | 焦段变化必须由信息或视点变化触发 |
| 速度、冲撞 | 广角近距离跟拍 | 远距离长焦适合表现目标迫近或混乱 |

## 7. 人物与对白场景规则

### 7.1 常规人物特写

可从以下范围试起：

- Super 35：50-75mm。
- 全画幅：75-105mm。

人物通常位于摄影机约 1.2-2.5 米外，可获得相对自然的五官比例。实际距离由人物脸型、景别、环境和镜头最近对焦距离决定。

### 7.2 主观或亲密特写

可从以下范围试起：

- Super 35：21-35mm。
- 全画幅：29-50mm。

摄影机靠近人物，使观众像站在人物面前。分镜必须明确这是有意的亲密、侵入、喜剧或不安，而不是误把广角当成长焦特写使用。

### 7.3 正反打

- 两个人物地位相当：尽量保持两侧机位到人物的距离、焦段类别、机位高度和视线偏角相近。
- 一侧广角近拍、一侧长焦远拍：会使两人的脸型、背景尺度和心理力量不对称，只能在有明确叙事目的时使用。
- 从同一机位只小幅改变焦距，容易形成跳切；应让景别或机位角度发生清晰变化。
- 焦距不能修复越轴。屏幕方向、视线方向和空间位置仍由轴线规则控制。
- 对白反应切镜应保持相同空间和焦段逻辑，避免听者反应突然出现完全不同的脸型和背景尺度。

### 7.4 多人对白

- 先用广角或标准焦段建立人物站位和视线网络。
- 再用中景、过肩、侧面近景、手部或关键道具补充关系。
- 三人以上场景若每个人都用独立长焦头像，空间关系容易消失。
- 焦点转移可在不换机位的情况下重分配叙事注意力，但必须测试焦点呼吸。
- 前景遮挡应来自现有场景，如肩膀、门框、桌案或人群缝隙，不得为了镜头感新增无关道具。

## 8. 运动镜头与焦距

### 8.1 推轨与变焦

| 方式 | 摄影机位置 | 透视关系 | 分镜写法 |
|:--|:--|:--|:--|
| 推轨/摄影机前移 | 改变 | 改变 | `dolly in / 摄影机沿轴线推进` |
| 拉轨/摄影机后移 | 改变 | 改变 | `dolly out / 摄影机沿轴线后退` |
| 光学变焦 | 不变 | 基本不变 | `optical zoom from 35mm to 70mm` |
| 滑动变焦 | 移动并反向变焦 | 主体大小近似不变，背景关系改变 | 必须写摄影机路径与变焦方向 |

不得把“推近”和“变焦”当成同义词。

### 8.2 广角运动

- 前后移动的视差明显，适合强化速度、空间穿越和人物趋近。
- 边缘运动显著，适合动作场面，但容易产生拉伸和空间漂移。
- 稳定器使用广角较易保持主体，但不能因此无限放宽焦段。

### 8.3 长焦运动

- 放大角度抖动、云台回弹和跟焦误差。
- 狭窄视角使人物横向运动更容易快速出框。
- 沿镜头轴线的距离变化显得较慢，适合压缩追逐距离或制造危险逼近。
- 跟拍必须预留运动空间，不能依赖突然裁切重新居中。

### 8.4 单条 AI 视频的限制

在一个连续生成的 AI 视频素材镜头内：

- 只保留一个主焦段逻辑。
- 禁止无解释地从广角变成长焦。
- 禁止同时执行换焦段、环绕、升降、快速推进和重新构图等多项复杂操作。
- 只有剧情明确要求光学变焦时，才写具体起止焦距和速度。
- 通过人物趋近、摄影机推拉或焦点转移改变景别时，不得写成“切换镜头焦距”。

推荐负面提示：

```text
Avoid changing lens mid-shot, unexplained zoom, abrupt field-of-view change, camera teleport, sudden crop, perspective drift, background scale drift.
```

## 9. 景深、光圈与对焦

### 9.1 景深由什么决定

景深由以下因素共同决定：

- 画幅大小。
- 焦距。
- 对焦距离。
- T 值或 F 值。
- 镜头设计、允许弥散圈与最终观看条件。

在相同画幅、相同拍摄距离和光圈下：

- 焦距越长，景深通常越浅。
- 距离越近，景深越浅。
- 光圈越大，景深越浅。
- 对焦越远、光圈越小，景深越深。

如果为了保持相同景别同时改变焦距和机位，不能只用“长焦景深一定更浅”进行判断。即使主体景深接近，背景大小、虚化形态和空间压缩仍然会变化。

### 9.2 分镜执行规则

- 对焦距离从相机的传感器或胶片平面标记量起，不从镜头前端量。
- 不得默认最大光圈等于电影感。
- 双人同框、多人走位或人物前后移动时，应为表演留出焦点容差。
- 大画幅、近距离、长焦、大光圈同时出现时，必须标记为高跟焦风险。
- 明亮环境需要保持浅景深时，优先使用 ND 滤镜，不以随意改变快门代替。
- 关键拉焦镜头必须写明起焦主体、落焦主体、触发动作和拉焦速度。

合格：

```text
焦点由前景账本缓慢转到背景人物眼睛，人物抬眼为拉焦触发点；保持机位和焦距不变。
```

不合格：

```text
焦点变到人物，然后镜头变成特写。
```

### 9.3 焦点呼吸

焦点呼吸是拉焦时视角或放大率发生变化，使画面看起来像轻微变焦。

以下场景优先选择低呼吸电影镜头，或在 AI 提示中明确禁止视角漂移：

- 前后人物之间的大幅拉焦。
- 关键道具到人物表情的焦点转移。
- 需要稳定构图的对白长镜头。
- VFX、虚拟制片、绿幕和需要镜头数据的镜头。

负面提示：

```text
Avoid focus breathing, field-of-view pulsing during rack focus, background scale change, unexplained reframing.
```

## 10. 定焦与变焦镜头

### 10.1 定焦

优点：

- 容易建立统一的全片镜头语言。
- 通常具有较大的最大光圈。
- 镜头组内若设计一致，色彩、对比、焦外和操作手感较稳定。

风险：

- 场地受限时容易为了迁就焦距而把机位放到错误位置。
- 频繁换镜增加现场时间。

### 10.2 变焦

优点：

- 适合纪录片、体育、演出、多机位和快速调度。
- 场地受限时可快速微调构图。
- 可将变焦本身作为明确的叙事动作。

拍摄中变焦时优先满足：

- 齐焦：变焦过程中保持焦点。
- 恒定 T 值：全焦段曝光不发生变化。
- 低呼吸：拉焦时视角变化受控。
- 后焦校准准确。

普通摄影变焦镜头可能是变焦时丢焦的非齐焦设计，不能未经测试就用于拍摄内变焦。

## 11. 变形宽银幕镜头

变形镜头不能直接套用球面镜头焦距表。

- 2× 变形镜头把水平方向压缩 2 倍记录，再在监看或后期拉开。
- 粗略而言，同一传感器上的 50mm 2× 变形镜头，水平视角接近 25mm 球面镜头，垂直视角仍接近 50mm。
- 1.3×、1.5×、1.6× 和 2× 的水平视角不同。
- 实际结果受 4:3、6:5、16:9、Open Gate 或裁切记录模式影响。
- 必须检查近距离脸型、边缘清晰度、椭圆焦外、水平眩光、焦点呼吸和不同距离下的压缩比变化。

分镜写法：

```text
Super 35，50mm 2× anamorphic；中近景，水平视角较宽，保留人物两侧环境；椭圆焦外与轻微水平眩光。
```

不得写：

```text
50mm 变形镜头等于 25mm 镜头。
```

原因：只有水平视角可作近似比较，垂直视角、焦外和镜头性格并不相同。

## 12. 执行稿的焦段写作精度

| 交付类型 | 焦段写作要求 | 示例 |
|:--|:--|:--|
| C 逐镜头精细分镜 | 画幅、实际或等效焦距、景深意图和连续性 | `Super 35 32mm，T2.8，中等景深` |
| AI 视频执行版 | 英文镜头感、构图和防漂移约束 | `35mm full-frame-equivalent lens look, natural perspective, medium depth of field` |

除非用户已经给出摄影机和镜头组，否则 C 级分镜也应将焦距标为“建议”，不得伪装成已锁定器材方案。

## 13. 写入固定镜头卡片的方法

焦段信息进入 `景别/机位/运镜` 字段，不新增字段，不改变 `shotlist-execution-format-template.md` 的固定字段顺序。

### 13.1 拍摄执行示例

```md
景别/机位/运镜：双人中景，人物视线高度，CM-01 固定，Super 35 32mm（约全画幅 46mm 视角），T2.8 中等景深；起幅保留两人腰部以上和桌面账本，落幅不改变焦距与机位。
```

### 13.2 主观压迫示例

```md
景别/机位/运镜：单人近景，略低机位，CM-02 低速正轴推进，全画幅等效 28mm 轻广角；摄影机从人物一臂半距离外推进，终点仍保留头顶与手部安全边距。
```

### 13.3 观察与隔离示例

```md
景别/机位/运镜：单人近景，门外侧面远机位，CM-01 固定，全画幅等效 100mm 中长焦；前景门框虚化遮挡，背景人群被压缩在人物身后。
```

### 13.4 拉焦示例

```md
景别/机位/运镜：前景道具特写转人物近景，视线高度，CM-01 固定，Super 35 50mm；焦点由前景信封转到背景人物眼睛，保持焦距、机位、构图和背景尺度不变。
```

## 14. AI 视频提示词写法

### 14.1 最小结构

```text
{焦距或焦段镜头感} + {机位距离/高度} + {景别} + {透视与空间效果} + {景深} + {摄影机运动} + {起幅和落幅} + {禁止视角漂移}
```

示例：

```text
35mm full-frame-equivalent moderate wide-angle lens look, eye-level medium close-up from intimate conversational distance, natural facial perspective with visible room depth, medium depth of field, slow straight dolly-in, start with both hands inside frame and end on the character's restrained expression, keep the same lens and camera axis throughout.
```

### 14.2 需要避免的模糊词

| 模糊写法 | 问题 | 改写 |
|:--|:--|:--|
| `电影感镜头` | 没有可执行参数 | 写焦段、距离、景别、景深和运动 |
| `高级长焦感` | 无法确定空间效果 | 写 `100mm equivalent, compressed background` |
| `镜头拉近` | 不清楚是推轨还是变焦 | 写 `slow dolly-in` 或 `slow optical zoom` |
| `切到特写` | 单条连续生成易乱切 | 拆镜，或由连续推进形成人物近景 |
| `背景虚化` | 缺少程度和焦点主体 | 写中浅景深、焦点落点和背景保留信息 |
| `广角但不要变形` | 目标冲突且不够具体 | 写适度广角、合理人物距离、人物居中安全区 |

### 14.3 AI 视频负面提示基线

按本镜实际风险取舍，不得机械复制全部内容：

```text
Avoid changing lens mid-shot, unexplained optical zoom, abrupt field-of-view change, focus breathing, perspective drift, background scale drift, sudden crop, abrupt reframing, camera teleport, axis flip, wrong gaze target, distorted face, stretched edge facial features, distorted hands, extra limbs, text, subtitles, watermark.
```

## 15. 连续性规则

### 15.1 同一连续场景

- 先确定该场的工作焦段或镜头组逻辑。
- 焦段显著变化必须对应视点、权力、信息或情绪变化。
- 相邻镜头保持人物脸型、背景尺度和空间距离可理解。
- 机位距离改变时，分镜必须说明观众关系为何改变。
- 同一镜头内不得无解释更换焦段或改变背景比例。
- 多批次生成时，读取上一镜的画幅、焦距、机位距离、起落幅和焦点状态。

### 15.2 允许焦段突变的情况

- 从客观观察进入人物主观。
- 从安全距离进入侵入式逼问。
- 从空间全貌进入证据、伤口或关键表情。
- 身份揭示后，人物权力关系发生逆转。
- 故意制造喜剧、惊吓、眩晕或认知断裂。
- 跨时间、跨空间或明确轴线重置。

即便允许突变，也必须有清晰剪辑点，不得把多个焦段塞进一个本应连续的 AI 视频素材镜头。

## 16. 常见失败模式与修正

| 失败模式 | 结果 | 修正 |
|:--|:--|:--|
| 每个特写都用长焦 | 人物和空间语言单一 | 根据亲密、观察、侵入或美化分别选择 |
| 每个建立镜头都用极广角 | 空间被夸大，人物失去重量 | 先判断是否需要空间信息，必要时用标准焦段建立 |
| 为了装下人物而不断后退 | 观众位置与情绪关系错误 | 先锁定机位，再换焦距或调整调度 |
| 无画幅却写精确焦距 | 产生伪精确 | 写全画幅等效或焦段镜头感 |
| 把推轨写成变焦 | 透视逻辑错误 | 分别写摄影机位移和光学焦距变化 |
| 拉焦时画面大小变化 | 焦点呼吸破坏构图 | 使用低呼吸镜头或加入禁止视角漂移 |
| 同一场极广角与长焦乱跳 | 脸型和空间尺度漂移 | 建立工作焦段，突变必须有叙事触发 |
| 长焦手持但无支撑说明 | 抖动被放大 | 标记脚架、肩扛、云台或稳定策略 |
| 大画幅长焦全开且演员走动 | 频繁脱焦 | 收光圈、调整距离、增加跟焦标记 |
| AI 镜头同时推、变焦、环绕 | 模型乱切或空间重建 | 每条素材保留一个主运动和一个焦段逻辑 |
| 只写“浅景深电影感” | 关键空间信息丢失 | 写焦点主体、虚化程度和必须保留的背景信息 |
| 广角人物放在画面边缘 | 脸和身体拉伸 | 留安全边距或选择畸变控制更好的镜头 |

## 17. 输出前自检

生成包含焦距信息的分镜后，逐镜检查：

### 17.1 物理逻辑

- [ ] 是否说明画幅或标注为全画幅等效？
- [ ] 焦距是否与景别、机位距离和空间容量相容？
- [ ] 是否把焦距变化误写成摄影机推拉？
- [ ] 是否把摄影机推拉误写成光学变焦？
- [ ] 长焦、近摄、大光圈是否标记跟焦风险？
- [ ] 镜头最近对焦距离是否可能限制构图？
- [ ] 变焦镜头若在拍摄中变焦，是否要求齐焦和恒定 T 值？
- [ ] 变形镜头是否写明压缩倍率和记录模式？

### 17.2 叙事逻辑

- [ ] 焦段是否服务本镜的叙事任务？
- [ ] 观众位置是否符合人物关系和情绪？
- [ ] 焦段突变是否有剧情、视点或情绪触发？
- [ ] 特写是亲密、侵入、观察还是美化，是否表达明确？
- [ ] 建立镜头是否承载有效信息，而不是为使用广角而存在？

### 17.3 连续性

- [ ] 正反打的机位距离、焦段和视线是否可理解？
- [ ] 相邻镜头的人物脸型和背景尺度是否无依据漂移？
- [ ] 同一 AI 视频素材是否保持一个主焦段逻辑？
- [ ] 拉焦是否保持机位、焦距和空间方向稳定？
- [ ] 多批次续写是否继承上一镜的焦距、焦点和起落幅？

### 17.4 AI 视频

- [ ] 是否避免模糊的“电影感、高级感、镜头拉近”？
- [ ] 是否写明焦段镜头感、景别、机位距离、景深和运动？
- [ ] 是否禁止无解释变焦、焦段变化、裁切和透视漂移？
- [ ] 人物头顶、手部和关键道具是否保留安全边距？
- [ ] 是否把真正的换机位、反打、俯拍或跨轴拆成独立素材镜头？

## 18. 快速决策卡

当需要快速选焦段时，依次回答：

```text
1. 本镜要交代空间还是隔离人物？
2. 观众应该离人物近还是远？
3. 机位在哪里，为什么？
4. 需要自然脸型，还是有意夸张透视？
5. 需要看清前后层次，还是压缩背景？
6. 演员是否前后移动，跟焦是否可执行？
7. 与上一镜的焦段、脸型和背景尺度是否连续？
8. 如果焦段突变，触发点是什么？
9. AI 视频是否保持一个主焦段和一个主运动？
```

无法回答第 2、3、8 项时，不应先写精确毫米数。
